# v1.0.0（2026-08-25）— MVP 闭环

## 功能

- 邮箱 + 密码注册/登录（scrypt 加密、httpOnly Cookie 会话）
- AI 自然语言创建日程："明天下午三点开会"、"从今天开始连续四天晚上八点学习 Python"（展开 4 天）
- 信息缺失追问（不猜测）：只给时间不给日期时，AI 问"哪天？"
- 语音输入（浏览器 Web Speech API，Chrome/Edge）
- 按日期查看日程（前一天/后一天/日历选择/回到今天）
- 日程编辑、删除；重复标识（每天/每周/每月）
- 手机 App 第一版：Expo + WebView 壳
- GitHub Actions 云端构建 + standalone 自动部署（`git push` 即上线）

## 技术要点

- Next.js 16 App Router + Turbopack；standalone 输出自包含产物
- Node 内置 SQLite（node:sqlite），`DATABASE_PATH` 环境变量指定位置
- 中国时区日期统一（backend/ai/date-utils.ts + frontend/src/lib/date.ts）
- 本地规则解析器 + OpenAI 兼容接口（可替换，失败回退）

## 验证结果

- 类型检查 ✅ 生产构建 ✅
- API 冒烟测试 17 项 ✅（注册/AI解析/连续四天/追问/增删改查/401）
- 页面渲染检查 7 项 ✅（按日期显示、今天不显示明天日程）
- mobile 类型检查 ✅

## 已知限制

- 重复事件只打标识，不按规则在后续日期展示（v2.0.0 解决）
- 不能用自然语言修改/删除已有日程（v2.1.0 解决）
- 只能看单日，无周/月视图（v3.0.0 解决）
- 网站为 http://IP:3000，无域名/HTTPS（待确认项 #1）
