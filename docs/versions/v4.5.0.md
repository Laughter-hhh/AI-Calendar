# v4.5.0（2026-08-31）— 安全导入、重叠布局与云端发布门禁

- ICS 导入先进入应用内预览面板，明确显示新增、重复、失败、样例与兼容性警告。
- 导入保持只追加和幂等，不修改或删除原日程；仅接受有效 `.ics` 文件。
- 日程可编辑开始/结束时间，服务端和界面共同校验时间格式与先后顺序。
- 单日提供事项/时间线切换并显示当前时间；周视图支持重叠任务并排和凌晨任务自动扩展。
- 压缩事项、月历和时间块布局，减少不必要换行。
- 新增发布测试流；GitHub Actions 在部署前运行 Lint、构建及五套回归测试。
- 服务器部署增加健康检查和失败自动回滚，电脑离线时仍可由云端完成发布。
