# v3.10.2（2026-08-28）— AI 提示词注入今天日期 + 兼容代码块输出

## 背景

实测 DeepSeek-V3：结构化能力明显强于 7B 小模型，但两个问题：

1. 输出可能带 ```json 代码块围栏 → 直接 JSON.parse 会失败
2. 模型不知道"今天是哪天"，把"明天"算成 2023-11-02（错误年份）

## 修复

1. 系统提示词注入**今天日期（中国时区）**，要求相对日期按此换算
2. 解析模型输出前自动剥离 ```json 代码块围栏

## 建议（重要）

把服务器 `/opt/ai-calendar/config.env` 的模型换成 DeepSeek-V3：

```
OPENAI_MODEL=deepseek-ai/DeepSeek-V3
```

然后 `pm2 restart ai-calendar`。7B 小模型对结构化任务明显不够用。
