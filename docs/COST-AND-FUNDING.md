# 成本与融资思考（决策笔记）

> 适用阶段：MVP 小范围测试。原则：**每笔投入对应一个验证目标；先免费/最便宜，按需升级；大项延后到正式发布。**

## 二、便宜的 AI Key（国内直连，OpenAI 兼容，改 3 行配置即可切换）

> 本项目 `config.env` 只需改 `OPENAI_BASE_URL / OPENAI_MODEL / OPENAI_API_KEY` 三行，平台随便换。

| 平台 | 特点 | 参考成本 |
|---|---|---|
| 硅基流动 SiliconFlow | 注册送额度，有免费模型，国内直连 | 免费起步；低价模型按量 |
| 智谱 GLM | GLM-4-Flash 有免费档 | 免费档够测试 |
| DeepSeek | 国内低价标杆 | 约 0.01~0.02 元/次解析量级 |
| 阿里云百炼（通义） | 新用户送免费额度 | qwen-turbo 很便宜 |

估算：一次"解析一句话"约几百到一千多 token，按低价模型算约 **0.01~0.02 元/次**，日常使用一个月几元到十几元。

语音识别（手机录音上传）需要平台支持 `/audio/transcriptions`；若不支持，手机端可用系统键盘"听写"（免费）。

## 三、免费 AI 选项

- 硅基流动：注册送额度 + 免费模型（OpenAI 兼容，首选试跑）
- 智谱 GLM-4-Flash：免费档
- 阿里云百炼：新用户免费额度
- Google Gemini / Groq：免费额度多，但国内访问不便（需要代理/海外支付）
- 手机键盘听写：语音识别的零成本方案

## 四、融资怎么想

**现阶段（MVP 验证期）不建议找投资**：

- 产品还没被验证，融资会大量消耗时间在沟通上，且过早稀释
- 本项目每月真实成本很低（几十元内），自筹完全够

**什么时候才考虑**：出现稳定日活、用户主动要求付费、或需要快速扩团队时，再接触早期机构。国内路径参考：奇绩创坛（YC 中国）、真格基金、红杉种子等早期基金/加速器。**在那之前，把时间花在用户身上。**

## 五、投入成本决策原则

1. **每笔钱对应一个验证目标**：例如配 AI Key 的几元钱，验证的是"模型版体验是否显著提升留存"——结果决定要不要持续花。
2. **免费 → 最便宜 → 按需升级**：先用本地规则/免费额度，不够再上低价模型，最后才考虑高级模型。
3. **大项延后**：域名/备案/Apple 账号/商店注册都是"正式发布"阶段的事，测试期不需要。
4. **设月成本上限（建议 ¥50）**：超了就降级（本地解析器就是天然降级方案），防止不知不觉超支。
5. **能免费就不付**：免费构建额度、免费测试、手机键盘听写等先用满。
