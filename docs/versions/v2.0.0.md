# v2.0.0（2026-08-25）— 完整重复事件

## 新增功能

1. **重复事件真正生效**：`每天 / 每周 / 每月` 的日程会按规则出现在后续日期（此前只是打标识）。
   - 每天：每天都出现
   - 每周：每周同一天出现
   - 每月：每月同一天出现（月末兜底：31 号的日程在只有 30/28 天的月份出现在月末）
2. **重复截止日期**：支持"持续到 N月N日"，到期后不再生成。
3. **AI 解析升级**：
   - "每天早上八点起床" → daily，从今天开始
   - "每周一晚上八点健身" → weekly，从下一个周一开始
   - "每月1号还款" → monthly，从下一个 1 号开始
   - "每天下午五点提醒喝水，持续到9月1日" → daily + repeatUntil
4. **仅删除本日**：重复日程提供「删此日 / 删系列」两个操作。删此日只影响这一天（写入例外表），系列其他日期保留。
5. **界面**：重复日程显示"每天/每周/每月"标签和截止日期。

## 数据模型变更（含旧库迁移）

- `events` 表新增 `repeat_until TEXT` 列（旧库自动 `ALTER TABLE` 补列）
- 新增 `event_exceptions(event_id, date)` 表：记录"某天不生成该重复事件"
- `PRAGMA foreign_keys = ON`：删除事件时级联清理例外记录

## 实现要点

- 重复展开在查询期完成（`listEvents` 按目标日期计算 occurrence），不预生成未来事件，数据量小、改规则即生效
- 时间/日期统一按中国时区（UTC+8）的日历日比较（`YYYY-MM-DD` 字符串 + UTC 解析）
- 月末兜底规则：基础日期是某月最后一天时，目标日也是其所在月最后一天即命中

## 已知限制（记录在 ROADMAP B1）

- 编辑重复事件时改的是整个系列（"编辑本日"未实现）
- 删除"本日"后再恢复该日（撤销例外）未实现
- 月末兜底策略是"命中月末"，与 Google Calendar 的"跳过缺失日"策略不同，如需切换需确认
