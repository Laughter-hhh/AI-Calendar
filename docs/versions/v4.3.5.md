# v4.3.5（2026-08-29）— 解析架构升级：模型理解 → 标准句式 → 本地规则执行

## 新架构（符合"模型理解语义 + 固定程序添加"）

```
用户自然语言
   │
   ▼
大模型（DeepSeek 等）：理解语义，改写成标准句式
   │  例："八月三十一之前完成年度审核" → "8月31日前完成年度审核"
   ▼
本地规则（固定程序）：按标准句式生成日程
   │  截止提醒 / 连续 / 重复 / 待办 / 点半 / 缺失追问 等确定性逻辑全在这里
   ▼
日程数据
```

## 为什么这样改

- 之前"截止语句强制绕过模型"虽然能用，但浪费了模型的语义理解能力
- 现在模型负责理解（中文数字、口语、歧义），本地固定程序负责确定性执行（截止 7/3/1 天 + 当天提醒、连续 N 天展开等）
- 截止提醒、待办识别等逻辑单一来源（`local.ts`），模型只是"翻译官"
