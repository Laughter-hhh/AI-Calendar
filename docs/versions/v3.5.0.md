# v3.5.0（2026-08-26）— 勾选完成事项

## 新增功能

1. **完成勾选**：单日视图与周视图的每条日程前有复选框，勾选后标题划线置灰；月视图已完成事件显示 ✓ 标记。再次点击可取消完成。
2. **AI 标记完成**：输入"完成整理""搞定会议"等，AI 找到对应日程并提示确认，确认后标记完成。
3. **完成状态展示**：事件详情中显示"已完成 ✅ / 未完成"；ICS 导出时已完成事件带 `STATUS:COMPLETED`。

## 实现要点

- `events` 表新增 `done INTEGER NOT NULL DEFAULT 0`（旧库自动 ALTER TABLE 补列）
- API 增删改查全链路支持 `done` 字段；`backend/ai/action.ts` 新增 `done` 动作类型（`完成/做完/搞定/划掉/标记完成`）
- 前端勾选后 PATCH `{ done }` 并刷新列表

## 验证结果

- 类型检查 ✅ 生产构建 ✅
- 冒烟测试 55 项 ✅（新增：标记完成、列表返回完成状态、AI 完成意图）
- 页面渲染检查 19 项 ✅（新增：日程行包含完成勾选框）

## 说明

- 完成状态保存在原日程上（不是新建/删除），取消勾选即恢复
- 重复事件勾选"完成"标记的是整条规则（该系列每次出现都会显示完成）；如需按次完成（如"今天完成了"），属于系列编辑语义的待确认项（见 ROADMAP #3）
