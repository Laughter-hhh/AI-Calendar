# v4.3.8（2026-08-29）— 修复"X月Y日完成事项"被误判为完成操作 / 截止提醒

## 问题

输入「八月三十一完成年度审核」无法识别，原因有两层：

1. **操作层误判**：`/api/ai/action` 把"完成"一律当成"标记已有日程完成"，找不到目标就返回"没找到包含年度审核的日程"，把创建流程拦住了。
2. **AI 标准化过度解读**：模型把"八月三十一完成"擅自补成"8月31日前完成"，变成截止提醒（截止 8.30），而按规则没有"前/之前/截止"应该是 8.31 当天的全天待办。

## 改动

- `backend/ai/action.ts`：带日期的"完成X"不再判定为完成操作（放行到创建流程）；"完成掉 / 标记完成 / 做完 / 搞定 / 划掉"仍按完成操作处理；"完成整理"这类无日期短句仍按完成操作。
- `backend/ai/service.ts`：AI 标准化后增加防线——原句不是截止句时，去掉标准句中被模型强加的"前/之前"（`isDeadlineSentence` 首次投入使用）。

## 验证

- 类型检查 ✅ 生产构建 ✅
