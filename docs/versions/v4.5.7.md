# v4.5.7

发布日期：2026-09-01

## 复合日程识别修复

- 支持“九月十号十五点到十八点助教开会，之后每周四和周五十五点到十八点当助教”这类复合输入。
- 前半句保存为一条指定日期的一次性日程。
- 后半句按星期拆成多条独立 `weekly` 日程，避免把周五吞进标题或只生成周四。
- “之后”会以此前一段日程的日期为锚点，重复系列不会从锚点之前开始。
- 配置 AI 服务时也保留复合句原文交给本地确定性规则执行，避免模型标准化吞掉其中一段。
