# v4.3.7（2026-08-29）— 有日期无时间 → 默认全天待办

## 规则变更（用户拍板）

「九月一号领取美团骑行卡」这类**有日期但没有时间**的输入，不再追问"几点"，直接创建**全天待办**。

| 输入 | 之前 | 现在 |
|---|---|---|
| 九月一号领取美团骑行卡 | 追问时间 | 9月1日全天待办 |
| 明天开会 | 追问时间 | 明天全天待办 |
| 明天下午三点开会 | 定时日程 | 定时日程（不变） |
| 晚上八点学习 | 追问日期 | 追问日期（不变） |
| 交报告 | 当天待办 | 当天待办（不变） |
