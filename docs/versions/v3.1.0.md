# v3.1.0（2026-08-26）— 参照主流日历应用的常用功能

本版本参考 Google Calendar / Apple 日历 / Outlook 的常用能力，全部无需产品确认即可实现的功能。

## 新增功能

1. **月视图**：单日 / 未来7天 / **月** 三种视图切换。月历网格（周日开头），每天显示最多 3 条日程 + 溢出计数，点击某天跳转到该日单日视图；支持上月/下月/今天/月份选择。
2. **事件详情展开**：点击日程行展开详情——日期、时间区间、重复规则、备注、原始说法（AI 解析前的原话）。
3. **增强编辑表单**：编辑时支持修改标题、日期、开始时间、结束时间、备注（此前只有标题和时间）。
4. **搜索**：按标题关键词过滤当前视图（单日/周/月均支持），无结果显示"没有匹配的日程"，可一键清除。
5. **ICS 导出**：把当前视图（今天/周/月）的日程导出为 `.ics` 文件，可导入 Google Calendar / Apple 日历 / Outlook。重复事件导出为 RRULE + EXDATE（例外日），全天事件用 DATE 格式。
6. **今日下一项提示**：单日视图且为今天时，顶部显示"下一项：15:00 开会"（按当前中国时区时间计算）。
7. **备注展示**：列表中日程下方直接显示备注摘要。

## 实现要点

- 月视图数据复用区间查询 `/api/events?from=&to=`，前端按月切换拉取
- 导出接口 `/api/events/export?from=&to=`：直接查询数据库（非重复事件按日 + 重复事件基础事件），重复事件输出 `RRULE:FREQ=DAILY/WEEKLY/MONTHLY[;UNTIL=...]`，例外日输出 `EXDATE`
- 搜索通过 `?q=` URL 参数实现（服务端传初始数据，客户端组件内过滤），与视图/日期参数可组合
