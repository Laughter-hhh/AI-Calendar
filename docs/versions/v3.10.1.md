# v3.10.1（2026-08-28）— AI 输出校正（模型结果兜底）

## 背景

接入硅基流动的 Qwen2.5-7B 后实测发现：7B 小模型对"严格结构化输出"的遵从度低——会把"明天"输出成日期 `2`、时间 `1`，不按 YYYY-MM-DD / HH:mm 格式。

## 修复

1. **提示词强化**：明确要求换算相对日期、时间必须严格 24 小时制 HH:mm，并加一个输入/输出示例
2. **输出校正层 `normalizeResult`**：
   - 模型输出的日期/时间格式不规范时，用本地规则解析器兜底换算（如"明天"→ 具体日期）
   - 仍无法校正的字段自动转为"追问"（missing），**杜绝脏数据入库**
3. 这样无论模型多弱，用户看到的要么是规范日程，要么是清晰的追问

## 建议

- 想获得更好的模型理解力：把 `config.env` 的 `OPENAI_MODEL` 换成硅基流动上的 `deepseek-ai/DeepSeek-V3`（更强、仍很便宜），改完 `pm2 restart ai-calendar`
