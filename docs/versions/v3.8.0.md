# v3.8.0（2026-08-26）— 手机端性能重构与移动界面优化

## 性能修复（手机切换不再卡）

1. **日期/视图切换改为前端即时切换**：此前每次切换都要让服务器重新渲染整个页面；现在切换只发一个轻量数据请求（`/api/events`），界面立即响应，用透明度提示加载中。URL 通过 `history.pushState` 同步（后退/前进可用）。
2. **周/月视图懒加载**：用 `next/dynamic` 按需加载，首次进入只下载当前视图所需代码。
3. 月视图不再重复请求（服务端已提供数据，移除冗余 fetch）。

## 移动界面优化（空间让给日程）

- 顶部栏紧凑化（小标题 + 用户信息一行）
- 工具条合并为两行：日期切换+视图切换一行；搜索+导出+导入一行
- 按钮改用小号紧凑样式；月历格子与事件行尺寸收紧
- 日程列表区域占比显著提升

## 架构变化

- 新增 `ScheduleArea`（客户端组件）统一管理 日期/视图/搜索 状态与数据加载；`page.tsx` 只做鉴权与首屏数据
- `DateNav`/`SearchBar`/`MonthView` 改为受控展示组件（不再直接操作路由）
