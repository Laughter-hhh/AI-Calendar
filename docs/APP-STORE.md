# 应用商店上架准备与成本说明

> 结论先行：**当前阶段建议先用"网页直接下载 APK"分发**（零成本、无审核），商店上架放到产品稳定后再做。本文说明各平台的准备、成本与更新难点。

## 一、当前方案：网页直接下载 APK（已就绪）

- 独立安卓安装包（APK），无需 Expo Go
- 分发页：http://39.106.121.28:3000/download
- APK 放到服务器 `/opt/ai-calendar/downloads/`，网站 `/api/download/` 提供下载
- 优点：零成本、无审核、立即可用；缺点：没有商店的自动更新与信任背书，需要用户手动允许"未知来源"

## 二、各平台上架成本

| 平台 | 一次性/年费 | 额外成本 | 备注 |
|---|---|---|---|
| Google Play（安卓） | **$25 一次性** | 无 | 个人开发者可上架；免费应用无抽成 |
| Apple App Store（iOS） | **$99/年** | 需一台 Mac + Xcode | 个人开发者可上架 |
| 国内安卓商店（华为/小米/OPPO/vivo/应用宝等） | 大多免费注册 | **软著**（软件著作权，代理约 ¥300~2000，周期 1~3 个月）；部分需备案 | 各商店单独审核 |
| 域名（可选） | 约 ¥30~100/年 | ICP 备案免费但需 1~2 周 | 见待确认项 #1 |

## 三、上架前需要准备的材料

1. **隐私政策页面**（各平台必填）：说明收集了邮箱、密码（加密存储）等数据；需要挂在网站上。← 可先做
2. **HTTPS**：当前是 http，商店审核会提示明文流量，上线前建议完成域名 + 备案 + 证书。
3. **应用图标与截图**：Expo 默认图标需替换为正式图标；商店要求若干张不同尺寸的截图。
4. **账号资质**：Google Play 需实名开发者账号；国内商店需个人实名 + 软著。
5. **内容评级问卷**（Google Play）：回答年龄分级问题。

## 四、更新会遇到哪些困难

**好消息（本项目架构的优势）**：App 是网页的容器，**99% 的功能更新都发生在网站侧，用户打开 App 即用最新版，不需要重新安装**。真正需要"更新 App"的情况只有改壳（图标/名称/原生能力）。

**需要面对的问题**：

| 问题 | 说明 | 应对 |
|---|---|---|
| 商店审核周期 | Google Play 通常几小时~几天；Apple 1~7 天且严格；国内商店 1~7 天不等 | 预留审核时间，避免"当天改当天发" |
| 版本号管理 | 每次构建需递增 versionCode，否则商店拒绝 | 已配置 EAS `autoIncrement` 自动递增 |
| iOS 壳应用政策 | Apple 对"纯网页套壳"应用审核严格（4.2 最低功能要求），可能被拒 | iOS 建议增加原生能力，或暂缓上架、先用网页版 |
| 国内商店软著 | 华为等要求软件著作权证书，办理需 1~3 个月 | 提前规划；个人可自行申请（免费但慢）或找代理 |
| 明文 HTTP 警告 | 商店扫描到 http 流量会警告 | 上线前升级 HTTPS |
| 多商店维护 | 国内各家商店都要单独上传、审核、回复 | 可用分发平台或先只上 Google Play |
| 数据合规 | 收集用户数据需隐私政策、删除账号渠道 | 提供"注销账号"入口（后续开发项） |

## 五、建议路线

1. **现在**：网页直下 APK（已完成）→ 找朋友安装测试
2. **产品稳定后**：做隐私政策页 + HTTPS → 上 **Google Play**（成本最低：$25 一次性）
3. **国内分发**：办软著 → 上华为/应用宝等（个人开发者可）
4. **iOS**：先观望；确认需要后再考虑 Mac + $99/年 + 原生能力增强，规避壳应用政策
