# v3.6.0（2026-08-26）— 共享日历

## 新增功能

1. **日历共享（只读）**：把自己的日历共享给同伴（输入对方注册邮箱），对方登录后即可在单日/周/月视图中看到你的日程（含重复事件展开），标注"来自 邮箱"。
2. **权限控制**：共享是**只读**——对方不能修改、删除、勾选完成你的日程（接口层同样拒绝，返回 404），AI 修改/删除也只操作自己的日程。
3. **共享管理页** `/shares`：共享 / 撤销 / 查看"别人共享给我的日历"（可取消查看），首页底部有入口。
4. 重复共享幂等；不能共享给自己；邮箱不存在会提示。

## 实现要点

- 新表 `calendar_shares(owner_user_id, viewer_user_id)`（自动建表，旧库无需迁移）
- 查询接口在 `listEvents` 层合并"本人 + 共享给我的用户"的事件，事件带 `ownerEmail` 字段标识来源
- 写操作（update/delete/完成/AI 动作）仍按 `user_id` 过滤，天然只允许操作自己的日程
