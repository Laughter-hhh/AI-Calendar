# v3.2.0（2026-08-26）— ICS 导入与事件颜色分类

## 新增功能

1. **ICS 导入**：与 v3.1.0 的导出形成互通闭环。上传 `.ics` 文件（Google Calendar / Apple 日历 / Outlook 导出），解析 `VEVENT` 并创建日程，支持：
   - 标题 / 全天或带时间 / 结束时间 / 备注
   - 重复规则（`RRULE` 的 DAILY/WEEKLY/MONTHLY + UNTIL）
   - 单次导入上限 200 条，返回成功/失败/跳过统计
2. **事件颜色分类**：参照主流日历应用的彩色标签——红/橙/绿/蓝/紫/无。创建/编辑时选择，列表、周视图、月视图显示彩色圆点。

## 实现要点

- 新增 `POST /api/events/import`（JSON `{ content }`），解析器处理 ICS 行折叠（unfold）、`DTSTART;VALUE=DATE`（全天）、`DTSTART:YYYYMMDDTHHMMSS`（带时间）、`DTEND`（仅同日导入）、`RRULE`
- 导入按浮动时间处理（忽略 TZID/Z），以中国时区语义入库；跨天事件暂只导入开始日（记录在已知限制）
- `events` 表新增 `color TEXT` 列（旧库自动 ALTER TABLE），API 增删改查全链路支持

## 已知限制

- ICS 导入忽略时区（TZID/Z），跨天事件只导入开始日
- 导入不去重（同一文件重复导入会生成重复日程）
- 颜色目前只作为展示标签，不参与筛选/统计
