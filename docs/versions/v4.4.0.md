# v4.4.0（2026-08-29）— 笔记本：记录"不确定什么时候做"的事

## 功能

新增「笔记本」页面（主界面 ⋯ 菜单 →「笔记本」，设置页也有入口），用来记录**不确定时间、但需要做的事**：

- 随手写一条（最多 500 字），不占用日历、不生成待办提醒
- 支持勾选完成、编辑、删除、一键清除已完成
- 「⏰ 转为日程」：AI 理解这句话 → 预览标题 / 日期 / 时间（可改）→ 确认后加入日历并从笔记本移出；信息不全时先追问补充

## 产品定位

- 笔记本条目**不是日程**：无日期无时间，不参与日历查询、不导出（ICS）、不影响"今日下一项"
- 与 AI 输入规则互不影响：输入框里说"交报告"仍是当天待办（规则不变）；只有主动写进笔记本才进入笔记本
- 时间一旦确定（或有了大致日期），用"转为日程"排进日历

## 改动

- 数据库新增 `notes` 表（`database/schema.sql` + `frontend/src/lib/db.ts` 内嵌结构，旧库自动建表，无需手工迁移）
- 数据层：`frontend/src/lib/notes.ts`
- 接口：`GET/POST /api/notes`、`PATCH/DELETE /api/notes/:id`（登录后按用户隔离）
- 页面：`frontend/src/app/notes/page.tsx`（服务端渲染列表）+ `frontend/src/components/NotesPanel.tsx`
- 入口：主界面 ⋯ 菜单、设置页；帮助页补充说明
- 测试：冒烟测试新增第 22 节（12 项），页面渲染检查新增笔记本页用例
