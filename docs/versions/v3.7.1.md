# v3.7.1（2026-08-26）— AI 服务独立配置文件

## 变更

- 新增 `backend/ai/config.ts`：读取 AI 服务配置时**环境变量优先，其次读独立配置文件** `/opt/ai-calendar/config.env`（在应用目录外，CI 部署不会覆盖）
- AI 解析服务与语音识别接口统一走该配置读取
- 目的：服务器上只需创建一个 `config.env` 并 `pm2 restart`，即可启用模型解析与手机端语音识别，无需改代码/重新构建

## 服务器启用步骤

```bash
sudo nano /opt/ai-calendar/config.env   # 填入 OPENAI_API_KEY 等（见 README）
pm2 restart ai-calendar
```

## 说明

- 不配置时一切照旧（本地规则解析 + 桌面浏览器语音）
- 手机端语音识别必须配置 `OPENAI_API_KEY`；也可以用手机输入法自带"听写"（零成本替代）
