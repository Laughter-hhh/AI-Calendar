# v2.1.0（2026-08-25）— AI 修改 / 删除日程

## 新增功能

用自然语言直接操作已有日程，无需手动编辑：

- **修改**："把学习改到晚上九点" → 找到「学习 Python」→ 时间改为 21:00
- **删除**："删除明天的会议" → 找到明天的「会议」→ 删除
- 支持日期定位："明天的会议改到下午三点"（同时改日期 + 时间）
- 找不到时给出提示："没找到包含"瑜伽课"的日程"
- 多个同名/相似日程时提示用户说清楚（"找到多个相关日程，请说清楚一点…"）
- 只说了"删除"没给对象时，自动取最近创建的日程作为候选

前端交互：输入条先调用 `POST /api/ai/action` 判断意图——是修改/删除则展示确认卡片（改了什么/删哪个），不是则走原来的创建流程。一切操作仍需用户**确认**后执行。

## 实现要点

- 新增 `backend/ai/action.ts`：纯逻辑解析器，事件搜索通过参数注入（数据层可替换）
- 新增 `POST /api/ai/action`：鉴权后解析，返回 `{ action, event, changes, message, candidates }`
- 复用 `resolveDate` / `resolveTime` 解析"动词后"的新时间和"动词前"的目标日期
- 候选搜索窗口：前后 30 天（含重复事件展开），按关键词 + 日期过滤，同名取离今天最近
- 前端 `AiInput.tsx` 新增 action 状态与确认卡片

## 已知限制（记录在 ROADMAP）

- 只支持"改时间/日期"和"删除"，尚不支持改标题/备注
- 修改重复事件时改的是整个系列（与 v2.0.0 一致，系列内单日修改未实现）
- 本地规则实现；配置 AI Key 后暂未走模型（可扩展 providers）
