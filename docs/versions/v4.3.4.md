# v4.3.4（2026-08-29）— 截止语句强制本地规则 + 常用语句测试套件

## 问题根因

配置 DeepSeek 后，解析走大模型；大模型不会做"截止提醒展开"（把"八月三十一之前完成年度审核"当成单条日程，且不去掉"完成"）。

## 修复

1. **截止类语句强制走确定性本地规则**（`service.ts` 路由）：无论是否配置 AI Key，"X月Y日前完成XX"都走本地解析器生成 7/3/1 天 + 当天 4 条提醒
2. 模型提示词增加截止任务兜底说明
3. 模型输出统一做标题清洗（去掉"完成/进行"等前缀）

## 测试套件

- 新增 `scripts/parser-cases.mjs`（`pnpm test:parser`）：16 条常用语句覆盖普通日程/半/连续/重复/截止(中阿数字)/待办/缺失追问/标题清洗
