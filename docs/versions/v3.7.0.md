# v3.7.0（2026-08-26）— 语音识别、自动更新、性能修复、日程分组

## 新增功能

1. **语音识别（手机端）**：桌面 Chrome/Edge 继续用浏览器内置语音；手机等不支持浏览器语音的环境，点麦克风改为**录音上传**，由服务端语音识别（OpenAI 兼容 `/audio/transcriptions`，需配置 `OPENAI_API_KEY`）。未配置时返回明确提示。
2. **自动更新提示**：新增公开接口 `/api/version` 返回版本号；页面每 5 分钟检测一次，发现新版本弹出"立即刷新"提示条（网页与手机 App 内都会生效，App 是网页容器所以刷新即更新）。
3. **手机切换日程卡顿修复**：
   - 周/月视图的区间查询从"按天循环查库"改为"批量查询 + 内存展开"，查询次数从每天 3 次降为每个日历所有者 3 次（性能提升数十倍）
   - pm2 进程内存上限从 500M 调到 768M，避免高峰期被守护进程重启导致"卡死"
4. **每日日程分组**：单日视图把日程分为「⏰ 定时日程」和「☑ 待办事项」两段（无时间日程自动归入待办）。

## 实现要点

- 新增 `frontend/src/lib/version.ts`（版本常量，发布时同步更新并打同号标签）
- 新增 `POST /api/ai/stt`（录音上传 → 语音识别），校验顺序：登录 → 文件 → 服务配置
- `listEventsRange` 重写为批量查询；`ecosystem.config.cjs` 内存上限 768M
- `EventList` 按 `startTime` 是否为空分组渲染

## 说明

- 语音识别需要服务器配置 `OPENAI_API_KEY` 才能用于手机端（桌面浏览器语音不受影响）
- APK 无需重新安装即可获得以上更新（网页容器）；仅当需要改壳时才需重新构建 APK
