# v4.3.0（2026-08-29）— 截止日期自动提醒

## 功能

识别"X月Y日前完成 XX"类截止任务，自动生成 4 条无时间待办提醒：

- 截止前 7 天："距离XX还有七天"
- 截止前 3 天："距离XX还有三天"
- 截止前 1 天："距离XX还有一天"
- 截止当天："今天截止：XX"

"X月Y日前"的有效截止日按 Y-1 处理（例："8月31号前" → 8.30 截止 → 提醒日 8.23 / 8.27 / 8.29 / 8.30）。

标题自动去掉"完成/交/做"等动作词，只留事项本身（"8月31号前完成实验报告" → 事项"实验报告"）。

- 标题清洗支持前导空格后再去前缀（去掉日期短语后残留空格导致"完成"未被清除的问题）
