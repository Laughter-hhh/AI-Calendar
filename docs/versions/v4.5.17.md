# v4.5.17

发布日期：2026-09-07

## 双周重复日程

- 支持“每两周 / 每隔两周 / 隔两周一次”等自然语言表达，可指定星期几、起始日期和时间段。
- 双周规则使用 biweekly 统一保存，按起始日期每 14 天展开；第 7 天不会误显示，第 14 天正常显示。
- AI 标准化结果若丢失双周语义，会自动回到本地确定性解析。
- ICS 导入和导出支持 FREQ=WEEKLY;INTERVAL=2。
- 日程列表、AI 确认卡片和笔记转换结果统一显示“每两周”。

## 回归验证

- 自然语言解析：双周、星期锚点、起止时间。
- API 展开：第 7 天不显示、第 14 天显示。
- ICS 双周导入。
