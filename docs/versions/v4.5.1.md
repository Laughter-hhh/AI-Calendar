# v4.5.1（2026-08-31）— 时间线留白与离线应用壳

- 单日时间线在 06:00 首条网格线与卡片外框之间增加 12px 顶部留白，时间标签和事件块保持同一坐标系。
- 增加网络状态监听：断网立即显示离线模式，恢复联网后自动刷新当前日期/视图。
- 增加 Service Worker：在 HTTPS 或 localhost 下缓存静态应用资源，并在冷启动无网时显示离线回退页。
- Service Worker 不缓存用户专属事件/笔记 API；日程数据继续使用按账号隔离的 localStorage 缓存，避免多账号串数据。
- 发布门禁新增离线资源与布局契约测试；版本号、Git 标签、线上版本接口保持同步。

> 当前公网地址仍为 HTTP IP。浏览器出于安全策略不会在该地址注册 Service Worker；页面已打开后仍可依靠本地日程缓存离线查看。配置 HTTPS/域名后即可启用完整的应用壳离线回退。
