# v3.9.0（2026-08-26）— 网页 / 手机双排版

## 变更

同一套网址、同一份代码，按设备宽度自动切换两套排版（Tailwind 响应式断点 `md:`）：

**手机端（窄屏）**：保持 v3.8.0 的紧凑布局——小号按钮、图标化导出/导入、两行工具条、紧凑日程行，最大化屏幕利用率。

**网页端（宽屏）**：

- 容器加宽（max-w-5xl），页边距与顶部留白更大
- 顶部显示副标题（AI 时间管理助手 · 一句话安排日程）
- 按钮恢复完整文字（前一天/后一天/回到今天/未来7天/月视图/导出 ICS/导入 ICS）并加大
- 日期选择框固定宽度、日程行与月历格子更宽松，正文更大
