# v3.10.0（2026-08-28）— 离线缓存、解析修复、混合识别模式

## 1. 手机离线使用（数据存本地读取）

- 新增本地缓存层 `frontend/src/lib/offline.ts`：日程数据（按日期/区间）成功请求后写入浏览器本地存储（localStorage，按用户隔离）
- **断网时读取缓存**：页面已打开的情况下断网，切换日期/视图会直接显示本地缓存的日程，并提示"离线模式"
- 联网时自动回退到实时数据并更新缓存

> 限制说明：冷启动完全断网时（App 打开即无网络）页面本体无法加载——这需要 HTTPS + Service Worker 的完整离线壳（列入路线图，依赖域名/备案决策）。当前方案覆盖"打开过之后断网使用"。

## 2. 离线解析修复（本地规则引擎）

- **"八点半"正确识别为 08:30**（此前被"八点"抢先匹配丢掉"半"；"下午三点半"→15:30 同理）
- **标题清洗增强**：去掉"进行/去/来做/去做/准备/组织/参加"等口语前缀——"八点半进行实验计划与果蝇收集" → 时间 08:30 + 标题"实验计划与果蝇收集"

## 3. 混合识别模式（联网 AI / 离线自动分割）

- **联网且有 Key**：走 OpenAI 兼容大模型解析（默认 gpt-4o-mini）
- **离线或未配 Key / 模型失败**：自动回退到本地规则解析器（自带"自动分割"：连续N天、重复规则、日期、时间、标题逐段拆解，缺失信息追问）
- 每次解析返回 `provider` 字段标明用的是哪个模式；配置方法见 README「配置 AI 服务」
