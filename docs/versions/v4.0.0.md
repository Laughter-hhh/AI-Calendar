# v4.0.0（2026-08-28）— 双界面（时间安排 + 单日事项）、无时间待办、界面优化、测试流

## 1. 无时间待办（修复"无法添加无时间日程"）

- 明确说"待办/无时间/没有时间/不限定时间"即可创建无时间待办（不再追问"几点"）
- 追问时回答"无时间"同样生效
- 标题清洗增强：去掉"待办："前缀残留冒号，标题更干净
- 新增"＋待办"快捷按钮（当前日期直接添加无时间待办）

## 2. 双界面切换

**时间安排界面（view=week）**：连续 7 天 × 时间块（6:00-23:00）：

- 不同任务用不同颜色时间块表示（按事件颜色）
- 顶部显示每天的全天/待办胶囊
- 点击日期头跳转到该日单日视图；时间轴可横向滚动适配手机

**单日事项界面（view=day）**：当日定时日程 + 无时间待办分段（已有）

## 3. 界面优化

- **刘海屏安全区**：顶部/底部内边距适配（viewport-fit=cover + safe-area），不再被手机时间/摄像头遮挡
- **去掉冗余**：首页不再显示大标题"AI Calendar"；"今日日程"标题压缩成小号单行
- **设置入口**：顶部新增"⚙️ 设置"，集中账号、共享日历、下载 App、离线说明、版本号；首页底部链接移除

## 4. 测试流与自主优化

扩展测试流并实际跑出 6 个问题、全部修复：

- 无时间待办建不出事件（事件条件要求 time 非空）→ 修复
- "待办："残留冒号 → 标题清洗修复
- 时间轴时间刻度渲染为 `6<!-- -->:00`（JSX 文本节点拆分）→ 模板字符串修复
- 设置页缺"版本"字样、测试断言旧标签"7天"→ 更新
