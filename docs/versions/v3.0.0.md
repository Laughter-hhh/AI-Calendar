# v3.0.0（2026-08-25）— 周视图、区间查询、备份脚本、API 文档

## 新增功能

1. **未来 7 天视图**：首页「单日 / 未来7天」切换，按天分组展示一周日程（重复事件按规则展开），可直接删除单日。
2. **日期区间查询接口**：`GET /api/events?from=YYYY-MM-DD&to=YYYY-MM-DD`（周视图的数据基础，后续月视图/日历也可复用）。
3. **数据库备份脚本**：`scripts/backup.sh`，一键备份数据库到 `backups/`，保留最近 14 份（WAL 模式下优先用 sqlite3 `.backup`，否则复制 db/wal/shm）。
4. **完整 API 文档**：`docs/API.md`，全部接口的参数、返回示例与测试命令。
5. **健康检查升级**：`/api/health` 增加数据库连通性探测（`db: "ok" | "error"`）。

- 冒烟测试 40 项 ✅（新增区间查询 200/400、健康检查 db 状态）

## 说明

- 周视图以 `?view=week` 呈现，`date` 参数为起始日
- 备份脚本在服务器上运行：`sudo bash /opt/ai-calendar/app/scripts/backup.sh`（脚本位于项目 `scripts/`，随部署更新）；建议用 cron 每天备份：`0 3 * * * root bash /opt/ai-calendar/scripts/backup.sh`（需将脚本放至持久目录或由 CI 拷贝）
